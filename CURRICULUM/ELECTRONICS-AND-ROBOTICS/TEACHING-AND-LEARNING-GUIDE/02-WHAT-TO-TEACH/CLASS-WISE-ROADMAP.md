# What to Teach: Electronics and Robotics Roadmap

This roadmap is dedicated to electronics and robotics for Classes 5–9. It progresses from basic electrical circuits to sensors, microcontrollers, mechanisms, and autonomous robotics. AI model training and AI-specific theory are outside this stream.

## Overall progression

| Stage | Core learning | Practical outcome |
|---|---|---|
| 1. Electricity and circuits | Power, conductors, insulators, open/closed circuits | Working LED circuit |
| 2. Components and control | Resistors, switches, LEDs, buzzers, transistors | Mini alarm or signal system |
| 3. Measurement and troubleshooting | Multimeter, voltage, continuity, circuit faults | Circuit testing challenge |
| 4. Sensors and microcontrollers | Inputs, outputs, Arduino, sensor readings | Automatic light or distance alarm |
| 5. Robotics and automation | Motors, drivers, movement, mechanisms, feedback | Small robot or automated mechanism |
| 6. Integrated engineering projects | Hardware, control logic, code, testing | Class-level robotics capstone |

## Class-wise project progression

| Class | Suggested major project | Main learning |
|---|---|---|
| 5 | Distance alarm or automatic light | Basic circuit, simple sensing, input/output |
| 6 | Smart dustbin | Sensor, microcontroller, servo, conditional logic |
| 7 | Colour-sorting station or alternative robot | Calibration, sensor rules, mechanism, motor control |
| 8 | Plant-care assistant | Environmental sensing, thresholds, safe control, testing |
| 9 | Autonomous obstacle-avoiding or line-following robot | System design, sensor-based navigation, motor control, evaluation |

Projects are proposals. Confirm the actual components, safety, time, and students' prior experience before selecting the final build.

## Concepts students should progressively master

| Concept | Expected practical understanding |
|---|---|
| Voltage | Potential difference that can drive current |
| Current | Flow of electric charge |
| Resistance | Limits current |
| Circuit | Recognize complete and broken paths |
| Polarity | Connect polarized components correctly |
| Series and parallel | Build and compare both |
| Breadboard | Use its internal connection pattern |
| Multimeter | Measure voltage, check continuity, and later measure current safely |
| Digital input/output | Read a button and control an LED |
| Analog input | Read a value across a range |
| Sensor calibration | Compare readings with real conditions |
| Actuator | Use a motor, servo, buzzer, or other output |
| Control logic | Decide when an output activates |
| Troubleshooting | Diagnose systematically rather than randomly changing wires |

Teach concepts when students need them for a build. Avoid presenting them all as an isolated theory block.
