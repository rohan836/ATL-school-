# What to Teach: Electronics and Robotics Roadmap

This roadmap is a proposed progression for Classes 5–9. It moves from simple circuits to sensor-based systems, robotics, and integrated projects. Adjust the pace and project hardware to students' readiness, timetable, and available ATL components.

## Overall progression

| Stage | Core learning | Practical outcome |
|---|---|---|
| 1. Electricity and circuits | Power, conductors, insulators, open/closed circuits | Working LED circuit |
| 2. Components and control | Resistors, switches, LEDs, buzzers, transistors | Mini alarm or signal system |
| 3. Measurement and troubleshooting | Multimeter, voltage, continuity, circuit faults | Circuit testing challenge |
| 4. Sensors and microcontrollers | Inputs, outputs, Arduino, sensor readings | Automatic light or distance alarm |
| 5. Robotics and automation | Motors, drivers, movement, feedback | Small robot or automated mechanism |
| 6. Integrated projects | Sensors, logic, code, hardware | Class-level capstone |

---

## Class 5 — Discovering Electricity

**Goal:** Understand basic circuits and create simple electronic systems using low-voltage components.

| Unit | Concept | Practical activity or project |
|---|---|---|
| 1 | Electronics in daily life | Identify electronics in the classroom and home |
| 2 | Electricity and safety | Identify safe and unsafe lab situations; learn approved low-voltage power |
| 3 | Conductors and insulators | Test materials with a simple circuit |
| 4 | Open and closed circuits | Build a circuit that can be switched on and off |
| 5 | Battery, wires, and LED | Make an LED light up |
| 6 | LED polarity | Investigate what happens when an LED is reversed |
| 7 | Resistors | Compare brightness using suitable resistor values |
| 8 | Switches | Build a simple room-light switch |
| 9 | Series circuits | Build a two-LED circuit |
| 10 | Parallel circuits | Compare series and parallel LED circuits |
| 11 | Buzzers | Create a sound-producing circuit |
| 12 | Simple alarms | Make a door-open alarm using a switch |
| 13 | Introduction to sensors | Explore light or distance sensing through a demonstration |
| 14 | Automatic systems | Build a simple automatic-light prototype |
| 15 | Project design | Plan and assemble a distance alarm or automatic light |
| 16 | Demonstration and reflection | Present, test, and improve the project |

**Capstone options:** A simple distance alarm or automatic light. Students explain the power source, input, output, and system response.

## Class 6 — From Circuits to Smart Systems

**Goal:** Use sensors and simple microcontroller programs to automate physical systems.

| Unit | Concept | Practical activity or project |
|---|---|---|
| 1 | Review of basic circuits | Build from a circuit diagram |
| 2 | Resistor and LED calculations | Choose a suitable LED resistor |
| 3 | Breadboard connections | Build without soldering |
| 4 | Switches and push buttons | Create a button-controlled signal |
| 5 | Transistor as a switch | Control an appropriate load through a transistor |
| 6 | Buzzer and alarm logic | Build an alert system |
| 7 | Microcontroller introduction | Explore Arduino and its pins |
| 8 | Digital output | Blink an LED through code |
| 9 | Digital input | Read a push button |
| 10 | Analog input | Read a potentiometer or analog sensor |
| 11 | Sensor readings | Measure distance or light level |
| 12 | Conditional logic | Respond to a sensor threshold |
| 13 | Servo motor | Control a servo position |
| 14 | System integration | Design a smart-dustbin mechanism |
| 15 | Build and debug | Assemble and troubleshoot |
| 16 | Project demonstration | Test, explain, and improve |

**Capstone:** Smart dustbin using a distance sensor and servo. Students identify input, processing/decision, and output.

## Class 7 — Sensors, Mechanisms, and Automation

**Goal:** Combine components and understand systems that detect, classify, and respond to objects.

| Unit | Concept | Practical activity or project |
|---|---|---|
| 1 | Circuit and microcontroller review | Build a sensor-controlled LED |
| 2 | Digital vs. analog signals | Compare button and sensor readings |
| 3 | Sensor calibration | Record readings at different distances |
| 4 | Thresholds and conditions | Build a proximity-triggered alert |
| 5 | RGB LEDs | Create a multi-colour indicator |
| 6 | Colour sensing | Explore how a colour sensor detects objects |
| 7 | Motors and actuators | Compare servo and DC motor behavior |
| 8 | Motor driver | Control a DC motor safely |
| 9 | Mechanical design | Design a simple sorting mechanism |
| 10 | Timing and sequencing | Create a timed sorting sequence |
| 11 | Multiple inputs | Combine a sensor with a button or second sensor |
| 12 | Reliability | Test with different objects |
| 13 | Project planning | Design a colour-sorting station |
| 14 | Build | Assemble the mechanism and electronics |
| 15 | Debug and improve | Improve detection and sorting accuracy |
| 16 | Project presentation | Demonstrate the station |

**Capstone:** Colour-sorting station. Students explain sensing, calibration, decision-making, and mechanical movement.

## Class 8 — Environmental Sensing and Intelligent Control

**Goal:** Design systems that monitor the environment and control outputs based on changing conditions.

| Unit | Concept | Practical activity or project |
|---|---|---|
| 1 | Embedded-system review | Build a sensor-to-output system |
| 2 | Voltage and current measurement | Measure a low-voltage circuit |
| 3 | Sensor calibration | Calibrate a soil-moisture or temperature sensor |
| 4 | Environmental sensors | Compare readings from sensors |
| 5 | Data collection | Record readings over time |
| 6 | Threshold control | Set an automatic trigger |
| 7 | Relay and load control | Study controlled switching with a safe low-voltage load |
| 8 | Motor and pump control | Explore a low-voltage pump or actuator |
| 9 | Feedback systems | Compare open-loop and closed-loop behavior |
| 10 | System logic | Create automation rules |
| 11 | Display and indicators | Show readings or system status |
| 12 | Power and reliability | Investigate power requirements and common faults |
| 13 | Project design | Plan a plant-care assistant |
| 14 | Build and integrate | Connect sensors, control logic, and outputs |
| 15 | Testing and refinement | Test under different conditions |
| 16 | Demonstration | Present the plant-care assistant |
| 17 | Project documentation | Create a circuit diagram and system explanation |
| 18 | Extension challenge | Add a sensor or improve control logic |

**Capstone:** Plant-care assistant that monitors soil moisture and controls an appropriate low-voltage watering mechanism. Sensor readings are estimates and should be calibrated.

## Class 9 — Engineering Systems and Intelligent Hardware

**Goal:** Independently design, test, and document a more advanced hardware project.

| Unit | Concept | Practical activity or project |
|---|---|---|
| 1 | System architecture | Break a project into input, processing, and output |
| 2 | Circuit design | Create and read a circuit diagram |
| 3 | Microcontroller programming | Use functions, variables, and conditions |
| 4 | Sensor data | Collect and analyze readings |
| 5 | Calibration and error | Measure uncertainty and improve readings |
| 6 | Motor control | Control motors using a driver |
| 7 | Communication | Explore serial or a suitable wireless module |
| 8 | Data logging | Record sensor data |
| 9 | Automation logic | Implement a multi-step control sequence |
| 10 | Feedback | Respond to changing conditions |
| 11 | System reliability | Test edge cases and component failures |
| 12 | Design constraints | Consider cost, power, size, and reliability |
| 13 | AI and hardware connection | Understand how a trained model produces a hardware decision |
| 14 | Project planning | Design an AI-connected or sensor-driven system |
| 15 | Prototype construction | Assemble and program |
| 16 | Testing | Evaluate using defined criteria |
| 17 | Improvement | Modify based on test results |
| 18 | Documentation | Prepare circuit, code, and test records |
| 19 | Final presentation | Demonstrate and explain |
| 20 | Reflection | Identify limitations and future improvements |

**Capstone:** A suitable AI classifier connected to hardware—for example, a simple classification input that triggers a physical or visual response. Use a model and hardware appropriate to the available devices; do not expect a large model to run directly on a basic microcontroller.

## Concepts students should progressively master

| Concept | Expected practical understanding |
|---|---|
| Voltage | Potential difference that can drive current |
| Current | Flow of electric charge |
| Resistance | Limits current |
| Circuit | Recognize complete and broken paths |
| Polarity | Connect polarized components correctly |
| Series and parallel | Build and compare both |
| Breadboard | Use its internal connection pattern |
| Multimeter | Measure voltage, check continuity, and later measure current safely |
| Digital input/output | Read a button and control an LED |
| Analog input | Read a value across a range |
| Sensor calibration | Compare readings with real conditions |
| Actuator | Use a motor, servo, buzzer, or other output |
| Control logic | Decide when an output activates |
| Troubleshooting | Diagnose systematically rather than randomly changing wires |

Teach these concepts when students need them for a build. Avoid presenting them all as an isolated theory block.
