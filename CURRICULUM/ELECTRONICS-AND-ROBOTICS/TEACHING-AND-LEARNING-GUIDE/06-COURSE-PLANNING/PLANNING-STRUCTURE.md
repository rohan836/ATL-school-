# Course Planning Structure

Use three connected levels of planning. This keeps the course organized and makes it easier to revise projects or lesson details without rewriting the entire curriculum.

## Level 1 — Annual roadmap

Defines:
- Class and course goals
- Unit sequence
- Core concepts
- Main projects
- Expected learning outcomes
- Approximate time allocation

The annual roadmap answers: **What should students learn this year, and in what order?**

## Level 2 — Unit plan

Defines:
- Unit objective
- Prior knowledge
- Concepts and vocabulary
- Project or practical activity
- Required components
- Sequence of project milestones
- Assessment evidence
- Safety and preparation notes

The unit plan answers: **How will students learn this group of concepts over several sessions?**

## Level 3 — Lesson plan

Defines:
- Learning objective
- Challenge question
- Required components and tools
- Short concept explanation
- Build steps
- Test method
- Common mistakes
- Safety considerations
- Student questions
- Reflection or exit question

The lesson plan answers: **What exactly will happen during this period?**

## Suggested lesson-plan structure

| Section | What to record |
|---|---|
| Class / unit / lesson | Where the lesson belongs |
| Learning objective | What students should be able to do |
| Challenge | The practical problem |
| Prior knowledge | What students already need |
| Components | Parts and quantities per group |
| Safety | Specific risks and precautions |
| Lesson flow | Challenge, predict, learn, build, test, improve, explain |
| Teacher questions | Questions that support reasoning |
| Expected result | What a successful build or test looks like |
| Troubleshooting | Likely errors and checks |
| Assessment | Evidence of student understanding |
| Reflection | What students learned and what to improve next time |

## Planning and revision

1. Confirm the actual timetable and number of sessions.
2. Check the ATL component inventory.
3. Select projects that fit the available components, time, and safety requirements.
4. Prepare and test the teacher prototype before the class.
5. Plan student build time and test time explicitly.
6. Use student observations to revise future lessons.
7. Keep the annual roadmap stable unless the learning sequence needs a meaningful change.

The roadmap in this guide is a starting framework. Detailed lesson plans should be created after confirming the timetable and component availability.
