# Electronics and Robotics — Classes 5–9

This stream is dedicated to **electronics, circuits, sensors, actuators, embedded systems, and robotics**. It is separate from the AI-only curriculum.

## Class roadmaps
- [Class 5](CLASS-5/README.md) — electricity and basic circuits
- [Class 6](CLASS-6/README.md) — microcontrollers and simple automation
- [Class 7](CLASS-7/README.md) — sensors, mechanisms, and robotics
- [Class 8](CLASS-8/README.md) — environmental sensing and control systems
- [Class 9](CLASS-9/README.md) — engineering systems and autonomous robotics

## Teaching guide
- [Teaching & Learning Guide](TEACHING-AND-LEARNING-GUIDE/README.md)

AI model training, datasets, classification, and generative AI lessons belong in the separate `AI-ONLY` stream. This curriculum may use ordinary programming for electronics and robot control, but its learning objectives are hardware and robotics.
