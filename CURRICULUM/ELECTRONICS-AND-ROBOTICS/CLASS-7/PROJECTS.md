# Class 7 — Interactive Robotics Projects

Combine sensor data, mechanisms, and programmed sequences. Test each component separately first.

## 1. Distance Detective
**Curriculum:** signals, calibration, thresholds, proximity alert.
**Materials:** controller, distance sensor, RGB LED/LEDs, optional buzzer.
1. Record readings at known distances.
2. Define two or three distance zones.
3. Program different light colors or alert patterns for each zone.
4. Let classmates move an object and guess its zone.
**Success:** explain calibration and why readings vary.

## 2. Color Sorting Challenge
**Curriculum:** color sensor, actuator, mechanism, timing, multiple inputs.
**Materials:** controller, available color sensor, servo, cardboard ramps/chutes, colored objects, suitable power.
1. Collect readings for each target color.
2. Write simple color rules.
3. Test the servo gate, then integrate it.
4. Sort objects one at a time and log accuracy.
5. Change lighting/object position and retest.
**Interactive twist:** timed round followed by an accuracy-improvement round.
**Success:** show sensor reading, rule, and mechanical action.
**Fallback:** use line-following/obstacle avoidance if a sensor and chassis are available; otherwise build a tabletop servo gate.

## 3. Mini Barrier Gate
**Curriculum:** servo/motor, sensor plus button, timed sequence, reliability.
**Materials:** controller, distance sensor or button, servo, craft-stick/cardboard barrier, base.
1. Build a lightweight barrier.
2. Test input and servo separately.
3. Program open → wait → close.
4. Test with toy cars and adjust to avoid early closure.
**Success:** explain the sequence and the effect of testing.

## 4. Motor Control Explorer
**Curriculum:** actuator comparison, motor driver, DC motor control.
**Materials:** controller, DC motor, suitable driver and low-voltage supply, optional button/sensor.
1. Identify driver connections with teacher.
2. Test start/stop and direction/speed if supported.
3. Trigger motor with a button or sensor.
4. Make a short movement sequence.
**Success:** explain why a driver is needed and how input changes motor behavior.

## Safety
Use suitable low-voltage drivers and supplies; never connect a DC motor to a controller pin. Keep fingers, hair, and loose objects away from moving parts. Select based on available components.
