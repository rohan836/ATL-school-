AI & Computing — Classes 5–9

One shared numbered curriculum framework with grade-level lesson plans and batch records.

Curriculum Documents

AI provides a single unified, full-year curriculum for Classes 5–9:

  • AI Curriculum (Classes 5–9) — HTML
  • AI Curriculum (Classes 5–9) — Markdown

Learning progression

  • Class 5: digital basics, algorithms, first code, simple data, AI concepts, guided capstone.
  • Class 6: computer systems, pseudocode, Python foundations, charts, model basics, mini-apps.
  • Class 7: Python fluency, functions/data structures, data cleaning, introductory ML, output verification.
  • Class 8: modular Python, data analysis, baseline models, evaluation, neural-network concepts, retrieval.
  • Class 9: software tests, reproducible data workflows, leakage-aware evaluation, source-grounded AI, independent capstone.

Delivery and safety

Use small approved datasets and provide paper/offline alternatives. No GPU, paid tool, public account, webcam, or external AI service is required. Never upload identifiable student data to public AI services. Test AI outputs, document mistakes, and keep humans responsible for consequential decisions.
