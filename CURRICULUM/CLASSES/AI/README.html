Course design

Six months · 12 sessions per month · 72 sessions total. Each core session is 60 minutes, with an optional 15-minute extension. The course progresses from computing foundations to Python, data, AI/ML, evaluation, responsible use and capstone projects.

One curriculum file per grade

C and D sections share the same learning sequence. To avoid duplicate documents, each grade has one common curriculum file containing the overview, month projects, 72-session plan, assessment guidance and teacher safety notes.

Learning progression

  • Class 5: computer/digital basics, algorithms, first code, simple data, AI concepts and guided capstone.
  • Class 6: computer systems, pseudocode, Python foundations, charts, model basics and useful mini-app.
  • Class 7: Python fluency, functions/data structures, data cleaning, introductory ML and output verification.
  • Class 8: modular Python, data analysis, baseline models, evaluation, neural-network concepts and retrieval.
  • Class 9: software tests, reproducible data workflows, leakage-aware evaluation, source-grounded AI and independent capstone.

Delivery and safety

Use small approved datasets and provide paper/offline alternatives. No GPU, paid tool, public account, webcam or external AI service is required. Never upload identifiable student data to public AI services. Test outputs, document mistakes and keep humans responsible for consequential decisions.
