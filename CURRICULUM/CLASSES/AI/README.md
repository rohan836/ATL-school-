# AI & Computing — Classes 5–9

## Course design
A six-month, 72-session curriculum: 12 sessions per month, with a 60-minute core lesson and optional extension time. The progression is practical, age-appropriate and cumulative. Computing fundamentals and Python/data skills are taught before students move into AI/ML concepts and projects.

## Learning progression
- **Class 5:** computer and digital basics, algorithms, first code, simple data, AI concepts, guided capstone.
- **Class 6:** computer systems, pseudocode, Python foundations, charts, model basics and a useful mini-app.
- **Class 7:** more fluent Python, functions/data structures, data cleaning, introductory ML and output verification.
- **Class 8:** modular Python, data analysis, baseline models, evaluation, neural-network concepts and small retrieval demos.
- **Class 9:** software testing, reproducible data pipelines, leakage-aware evaluation, source-grounded AI and an independent capstone.

## Delivery and safety
Use low-cost tools and small approved datasets. Provide paper/offline alternatives. No GPU, paid tool, public account, webcam or external AI service is a prerequisite. Do not upload identifiable student data. Test outputs, document mistakes, and keep human review for consequential decisions.
