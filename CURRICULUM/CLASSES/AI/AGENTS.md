## 1. Core Structure

- **Master File (`AI-CURRICULUM-CLASSES-5-TO-9.md`):** Keep the exact Term 1 and Term 2 tables across `Class 5` through `Class 9` verbatim with no extra prose added.
- **Per-Class Files (`Class-<N>/CLASS-<N>-CURRICULUM.md`):** Keep the exact Term 1 and Term 2 rows (`| # | Content & Core Concept *(Taught in ALL Grades 5–9)* | Class <N> |`) matching the master curriculum verbatim.
- **Strict Track Separation:** Never reference external Electronics classes inside AI curriculum files.
- **Forbidden Files:** Do NOT create separate `PROJECTS.md` files or `README.html` / `AGENTS.html` / `CLAUDE.html` / `SKILL.html` files.
- **HTML Generation:** Run `python3 CURRICULUM/build_html.py` after updating any Markdown file.
