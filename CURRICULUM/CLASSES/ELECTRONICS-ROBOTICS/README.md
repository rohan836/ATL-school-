# Electronics & Robotics — Classes 5–9

## Single shared curriculum

Use the [Unified Electronics & Robotics Curriculum](UNIFIED-CURRICULUM.md) as the source of truth for lesson topics, grade-level differentiation, assessment, safety, and project planning. Classes 5–9 follow one shared sequence; the depth, independence, and capstone expectations increase by grade.

The curriculum is shared across C and D sections. Keep each section's timetable, attendance, project progress, and other operational records separate, but do not create duplicate versions of the lesson sequence.

## Equipment and safety

Review lab stock and exact board/sensor specifications before promising any build. Use teacher-approved low-voltage wiring instructions and provide a no-hardware alternative whenever required parts are unavailable. AI & Computing remains a separate pathway.
