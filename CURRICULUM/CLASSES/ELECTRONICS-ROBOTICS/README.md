# Electronics & Robotics — Classes 5–9

**Atal Thinking Lab · Progressive, hands-on curriculum**

The curriculum progresses from electricity and simple circuits in Class 5 to component testing, Ohm’s law, transistor and relay switching, sensors, motors, Arduino/ESP32, and robotics projects by Class 9.

## Safety

Use low-voltage DC for student-built circuits. Do not allow students to probe household mains or build exposed mains-powered circuits. Use appropriate current-limiting resistors, drivers, and external supplies where needed. Check board and component specifications and supervise tool use.
