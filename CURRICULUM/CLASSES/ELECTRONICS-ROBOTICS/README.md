# Electronics & Robotics Curriculum

**Atal Thinking Lab · One shared curriculum for Classes 5–9**

This is a single curriculum organized into eight modules for all Classes 5–9—not separate curricula by class. The same module framework is used across grades; teaching depth and project complexity can be adjusted to the learners.

## Safety

Use low-voltage DC for student-built circuits. Students must not probe household mains or build exposed mains-powered circuits. Teach AC using diagrams or teacher-prepared isolated low-voltage demonstrations. Use appropriate current-limiting resistors, drivers, and supplies; check board/component specifications and supervise tool use.
