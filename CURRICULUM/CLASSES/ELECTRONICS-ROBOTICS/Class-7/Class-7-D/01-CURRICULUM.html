Course focus: Combine sensors, motors, mechanisms, and control sequences to create a basic robotic system.

Learning sequence

UnitConceptPractical activity or build
1Circuit and controller reviewBuild a sensor-controlled LED
2Digital and analog signalsCompare button and sensor readings
3Sensor calibrationRecord distance readings at known positions
4Thresholds and conditionsCreate a proximity-triggered alert
5RGB LEDBuild a multi-colour status indicator
6Colour sensor basicsExplore how a sensor detects object colour
7ActuatorsCompare servo and DC motor behavior
8Motor driverControl a DC motor using a suitable driver
9Mechanical designSketch a simple sorting mechanism
10Timing and sequenceCreate a timed motor/servo sequence
11Multiple inputsCombine a sensor with a button or second sensor
12Reliability testingTest with different objects and conditions
13Project designPlan a colour-sorting station
14BuildAssemble sensor, mechanism, and control
15Debug and improveImprove sorting repeatability
16DemonstrateExplain sensor, control sequence, and mechanism

Capstone

Colour-sorting station. A colour sensor reads an object and a servo or motorized mechanism moves it into a selected path. The project is based on sensor readings and programmed rules—not AI model training.

Expected outcomes

Students can calibrate a sensor, control a motor through a driver, describe a mechanical sequence, and evaluate a prototype through repeated tests.

Practical note

The project requires a suitable colour sensor and mechanical parts. If those are unavailable, substitute a line-following or obstacle-avoiding robot using the components on hand.
