## Project Assignment — LED Traffic Signal

| Assignment Section | Instructions and Information |
|---|---|
| 1. Project Title | LED Traffic Signal |
| 2. Aim of the Project | Build a miniature traffic signal using LEDs and learn how a basic electronic circuit operates. |
| 3. Project Problem | How can we represent the red, yellow, and green lights of a road traffic signal using a simple electronic circuit? |
| 4. Learning Objectives | Identify LED polarity; explain the purpose of a resistor; understand current flow and simple circuits; assemble and test an electronic circuit; describe how traffic lights guide road users. |
| 5. Introduction | Write a short introduction about road traffic signals, what each signal means, and why traffic signals are important. |
| 6. Components Required | Red LED, yellow LED, green LED, suitable current-limiting resistors, breadboard, jumper wires, and a low-voltage battery or approved lab supply. |
| 7. Component Description | Describe the purpose of each component. Explain how an LED produces light and why a resistor is needed. |
| 8. Basic Electronics Concepts | LED polarity, electrical current, voltage, resistance, current limiting, open circuit, and closed circuit. |
| 9. Working Principle | Explain how the three LEDs represent traffic signals. Describe the intended signal sequence and how each LED is controlled. |
| 10. Circuit Diagram | Draw and label the circuit. Show the power source, each LED, its resistor, and all connections. |
| 11. Construction Procedure | Write the steps followed to assemble the circuit: identify component terminals, connect each LED through a resistor, check connections, and power the circuit only after inspection. |
| 12. Signal Sequence | Record the planned signal sequence and explain what each light indicates. For a basic manual model, describe how the lights are switched; for a timed model, explain the timing method used. |
| 13. Programming | Not required for the basic circuit. If an Arduino is used, include the board, pin connections, code, and a short explanation of the code. |
| 14. Testing Procedure | Test each LED separately, then test the complete signal. Check polarity, connections, and resistor values if an LED does not light. |
| 15. Observation Table | Record the LED tested, circuit condition, expected result, actual result, and any change made during testing. |
| 16. Result | Describe whether the traffic signal model worked as expected. |
| 17. Real-Life Applications | Explain how traffic signals are used at road intersections and how signal sequencing helps organize traffic. |
| 18. Problems Faced | Record any difficulty encountered while selecting components, drawing the circuit, assembling it, or testing it. |
| 19. Troubleshooting | Explain the checks or changes used to solve each problem. |
| 20. What We Learned | Write the main electronics concepts and practical skills learned from this project. |
| 21. Conclusion | Summarize the project, its working, and the learning gained. |
| 22. Future Improvements | Suggest possible extensions, such as timed switching, a pedestrian signal, a pushbutton, or Arduino-based control. |
| 23. Project Evidence | Add a labelled circuit diagram and, where permitted, a photograph or drawing of the completed model. |
| 24. Teacher Feedback | Space for the teacher's comments and suggestions. |

## Safety Notes

- Use only low-voltage batteries or an approved, current-limited lab supply.
- Never connect the student-built circuit to household mains electricity.
- Use a suitable resistor in series with each LED.
- Check LED polarity and circuit connections before switching on the power.
- Disconnect power before changing any wiring.
- Ask the teacher to check the circuit before powering it.
