# ATL Facilitator Session Sheet Template (70 Min · 8 Groups of 5)

**Use this exact flow for every Class 5–9 Electronics session.**  
No textbook definitions, no history stories, and no step-by-step pin-to-pin wiring handouts.

---

```
================================================================================
CLASS: [5 / 6 / 7 / 8 / 9]  |  TERM: [1 / 2]  |  WEEK: [01–28]
COMPONENT / TOPIC: [Component / Topic Name]
FORMAT: 70 min · 40 Students in 8 Groups of 5
================================================================================
```

## 1. Visual Behavior Intro *(10–15 min · Projector)*

- **Chrome Diagram:** Show the physical part, pin labels (`+` / `−` or `VCC / GND / OUT`), and safe voltage limit.
- **Short YouTube Demo (2–4 min):** Show *only* how the component behaves in real life (what triggers it, what moves, or what lights up).
- **Group Challenge Prompt:** Pick a challenge (`Project 1`–`Project 5`) from that week's row in `CLASS-<N>-CURRICULUM.md`.

---

## 2. Open-Ended Group Build & Debugging *(35–40 min · 8 Groups of 5)*

- **ATL Inventory Trays:** Groups collect their own parts from verified lab stock (`main ATL school/Electronic component sorted list/`).
- **Zero Wiring Recipes:** Facilitator does not hand out step-by-step wiring sheets. When a circuit fails, guide the group through the 4 checks:
  1. Power & Polarity (`+` / `−`, resistor protection).
  2. Breadboard / wire contact seated firmly.
  3. Resistor value & sensor pin match.
  4. Measure or isolate (DMM / Serial Monitor / Oscilloscope in higher grades).

---

## 3. Group Showcase & 3-Box Debugging Log *(10 min · 5 min Bench Reset)*

- **Quick Showcase:** 2–3 groups demonstrate their working build and show how they solved an obstacle.
- **Student Notebook Entry (3-Box Debugging Log Only):**

| Notebook Box | What Each Student Writes (1–2 Short Lines) |
|---|---|
| **1. Problem** | *(What challenge prompt or real problem did our group tackle today?)* |
| **2. What Broke** | *(What failed during our first test—wrong leg, loose jumper, resistor value, code bug?)* |
| **3. How We Fixed It** | *(Exact wiring, component, or code change that got it working.)* |
