Course focus: Build environmental monitoring and automatic control systems with attention to measurement, reliability, and safe power handling.

Learning sequence

UnitConceptPractical activity or build
1Embedded-system reviewBuild a sensor-to-output system
2Voltage and current measurementMeasure a low-voltage circuit with a multimeter
3Sensor calibrationCalibrate a soil-moisture or temperature sensor
4Environmental sensorsCompare sensor readings under different conditions
5Data collectionRecord readings and organize them in a table
6Threshold controlSet an automatic trigger based on measured values
7Switching and relay principlesStudy safe low-voltage load switching
8Motor or pump controlOperate a suitable low-voltage actuator
9Open-loop and closed-loop controlCompare fixed action with sensor-based response
10Control rulesDesign conditions for an automatic system
11Status displayShow sensor values or system state
12Power and fault handlingIdentify power needs and common faults
13Project designPlan a plant-care assistant
14Build and integrateConnect sensors, controller, and output
15Test and refineTest dry/wet or changing environmental conditions
16DemonstrateExplain system operation and safety
17DocumentationDraw circuit and block diagrams
18ExtensionAdd a sensor or improve the control response

Capstone

Plant-care assistant. Monitor soil moisture and operate an appropriate low-voltage watering mechanism when needed. Include a safe stop or fail-off behavior for sensor faults.

Expected outcomes

Students can measure and interpret sensor values, describe calibration, distinguish open-loop and closed-loop control, and design a sensor-based automation system.

Practical note

Keep water physically separated from powered electronics. Use only teacher-approved low-voltage pump arrangements and suitable driver/power components; do not have students work with mains wiring.
