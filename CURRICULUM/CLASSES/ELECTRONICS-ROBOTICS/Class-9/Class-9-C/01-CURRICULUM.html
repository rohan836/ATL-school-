Course focus: Design, build, program, test, and document an autonomous robotic system using sensors, control logic, motors, and mechanical design.

Learning sequence

UnitConceptPractical activity or build
1System architectureMap a system into inputs, controller, outputs, and power
2Circuit diagramsDraw and interpret a circuit schematic
3Structured microcontroller codeUse variables, functions, conditions, and loops
4Sensor dataCollect and interpret real sensor readings
5Calibration and errorCompare measured values and discuss uncertainty
6Motor controlUse a motor driver to control speed/direction where supported
7Communication basicsExplore serial communication or an available suitable module
8Data loggingRecord robot or sensor test data
9Control sequencesImplement a multi-step behavior
10Feedback controlMake behavior respond to changing sensor input
11ReliabilityTest edge cases and common component faults
12Engineering constraintsConsider cost, power, size, and reliability
13Robot navigationExplore line following, obstacle avoidance, or a simple maze
14Capstone designPlan an autonomous robot and define success criteria
15Prototype buildAssemble chassis, sensors, motor driver, and controller
16TestingRun repeatable tests and record results
17ImprovementTune sensor placement, logic, or movement
18DocumentationPrepare circuit, block diagram, code notes, and test records
19DemonstrationDemonstrate and explain the robot
20ReflectionState limitations and future improvements

Capstone

Autonomous obstacle-avoiding or line-following robot. Students use sensor inputs and programmed control rules to guide movement. Choose the robot type based on the actual available chassis, sensors, motors, and driver boards.

Expected outcomes

Students can plan a hardware system, build and program a robot, test its behavior using evidence, diagnose faults, and document design choices and limitations.

Practical note

This is an electronics-and-robotics capstone. AI model training, datasets, and classifier deployment are not part of this class curriculum; those belong in the separate AI-only stream.
