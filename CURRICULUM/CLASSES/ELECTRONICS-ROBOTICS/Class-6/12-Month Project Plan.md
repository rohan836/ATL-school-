# Class 6 — 12-Month Electronics & Robotics Project Plan

This plan develops students’ knowledge from basic electronics and Arduino programming to sensor-based automation and integrated projects. Each project introduces a concept that supports the next stage.

| Month | Project | Main Concepts |
|---|---|---|
| 1 | Arduino LED Blinking | Arduino basics, digital output, LED, resistor |
| 2 | Interactive LED Traffic Signal | Timing, sequencing, multiple outputs |
| 3 | Pushbutton Electronic Quiz Buzzer | Digital input, buttons, buzzer, logic |
| 4 | Automatic Night Lamp | LDR, analog input, threshold, automatic switching |
| 5 | Ultrasonic Distance Meter | HC-SR04, distance measurement, sensor readings |
| 6 | Mini Parking Radar | Distance bands, LEDs, buzzer, feedback |
| 7 | Motion-Activated Room Light | PIR sensor, LDR, combined conditions |
| 8 | Smart Plant Monitor | Soil-moisture sensor, calibration, analog values |
| 9 | Classroom Weather Station | Temperature, humidity, sensor display |
| 10 | Touchless Smart Dustbin | Ultrasonic sensing, servo motor, automation |
| 11 | Pedestrian Crossing Model | Detection, signal timing, state sequence |
| 12 | Smart Room Automation Model | Integrated sensors, outputs, control logic |

## Learning progression

- **Months 1–3:** Basic circuits, inputs, outputs, and control.
- **Months 4–6:** Sensors, measurement, and threshold-based decisions.
- **Months 7–9:** Combining sensors and displaying information.
- **Months 10–12:** Automation, mechanisms, and integrated systems.

Each project should include a component list, circuit diagram, construction, testing, troubleshooting, and student explanation.
