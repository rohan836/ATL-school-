Course focus: Move from basic circuits to microcontroller-controlled devices and simple automation.

Learning sequence

UnitConceptPractical activity or build
1Circuit review and diagramsRebuild a circuit from a simple schematic
2Resistor and LED calculationsSelect a suitable LED resistor
3Breadboard connectionsBuild and inspect a solderless circuit
4Push buttons and switchesMake a button-controlled indicator
5Transistor as a switchControl a suitable low-voltage load using a transistor
6Buzzer and alarm logicBuild a simple alert circuit
7Microcontroller basicsIdentify Arduino board, pins, and USB connection
8Digital outputBlink an LED using code
9Digital inputRead a push button
10Analog inputRead a potentiometer or analog sensor
11Sensor readingsMeasure light or distance
12Conditional controlActivate an output when a sensor crosses a threshold
13Servo motorControl servo position
14System designPlan a sensor-operated smart-dustbin lid
15Build and debugIntegrate distance sensor, servo, and controller
16Test and presentTest the lid response, improve, and explain

Capstone

Smart dustbin. A distance sensor detects a nearby hand; a microcontroller controls a servo to open and close the lid.

Expected outcomes

Students can distinguish input and output, connect a basic sensor, write simple input/output code, control a servo, and troubleshoot a small automated system.

Practical note

Test the sensor and servo separately before integration. Power the servo according to its specifications; do not assume a microcontroller pin can supply its motor current.
