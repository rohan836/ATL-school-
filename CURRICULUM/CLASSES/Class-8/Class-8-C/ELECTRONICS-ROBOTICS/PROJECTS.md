# Class 8 — Interactive Environmental Sensing and Control Projects

Students measure, compare, and use data to control a low-voltage system.

## 1. Plant Needs a Drink?
**Curriculum:** calibration, environmental readings, data, threshold control.
**Materials:** controller, soil-moisture sensor, optional LEDs/display, pot/soil.
1. Read dry and damp soil (do not immerse electronics).
2. Record several readings and compare.
3. Choose a threshold and show “needs water / okay.”
4. Test a different sample and discuss threshold limitations.
**Interactive twist:** teams predict mystery soil readings before testing.
**Success:** explain calibration and a sensor limitation.

## 2. Automatic Plant Watering Prototype
**Curriculum:** threshold control, switching, actuator, fault handling.
**Materials:** moisture sensor, controller, suitable low-voltage pump/actuator, proper driver and supply, tubing/container/tray.
1. Test sensor and pump/driver separately.
2. Trigger watering only when soil is judged dry.
3. Add a maximum run time and fail-off behavior.
4. Test with small measured amounts in a tray.
5. Log readings and activation.
**Interactive twist:** teams tune thresholds/duration and compare overwatering prevention.
**Success:** demonstrate trigger, actuator, safety stop, and evidence.

## 3. Classroom Comfort Meter
**Curriculum:** environmental sensors, data collection, display/status.
**Materials:** available temperature sensor, controller, optional LEDs/display.
1. Take readings in different locations/times.
2. Record conditions such as shade or sunlight.
3. Create class-defined indicator bands.
4. Compare and discuss measurement limitations.
**Interactive twist:** predict which location reads higher, then verify.
**Success:** explain the measurement and why it may not represent the whole room.

## 4. Feedback-Controlled Low-Voltage Fan
**Curriculum:** open/closed loop, control rules, actuator switching.
**Materials:** controller, temperature sensor, suitable driver, low-voltage fan and supply.
1. Run fan manually through approved driver.
2. Add sensor and threshold rule.
3. Compare fixed-time operation with sensor-triggered response.
4. Test near threshold and refine to avoid rapid switching.
**Success:** describe feedback and distinguish it from a fixed schedule.

## Safety
No mains-powered pumps, fans, or relays in student builds. Keep water away from powered circuits; use supervised low-voltage setup, suitable driver, and fail-off/max-runtime behavior.
