## Conventions

- **Class sections:** C and D are sections of each class, stored as folders such as `Class-5-C` and `Class-5-D`. Timetable files call these groups **batches**; both terms refer to the same group. When creating paths or records, use the full folder form `Class-<number>-<section>`.

## Navigation maintenance
- Search the repository before adding a new record or topic.
- Keep one clear authoritative source for each item; link to it from here when useful.
- Add new knowledge areas as they actually emerge. Do not predefine every possible future category.
- Remove or change an index entry only when the source location or record status has actually changed, and follow the repository's change-control rules.
