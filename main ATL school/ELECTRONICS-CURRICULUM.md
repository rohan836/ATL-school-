# Electronics Curriculum

| S.No. | Module Name | Content |
|:---:|---|---|
| **01** | **Foundations of Electricity** | What is electricity • Atoms, electrons, and electrical charge • Voltage (push), Current (flow), and Resistance (opposition) • AC (Alternating Current) vs DC (Direct Current) • Frequency, waveforms, and power sources • Conductors, insulators, and semiconductors • Closed circuits, open circuits, and short circuits • Laboratory electrical safety rules |
| **02** | **The Solderless Breadboard** | Breadboard construction and purpose • Internal horizontal power rails ($V_{CC}$ and GND) • Internal vertical 5-pin terminal strips • Center IC division channel • Jumper wires: male-to-male, male-to-female, female-to-female • Breadboard wiring rules and color coding conventions • Common breadboard wiring mistakes and troubleshooting |
| **03** | **Digital Multimeter (DMM)** | Multimeter layout: display, rotary selector switch, and probe jacks • Measuring DC Voltage ($V_{DC}$) and AC Voltage ($V_{AC}$) • Continuity testing and audible buzzer (finding broken wires and shorts) • Measuring Resistance ($\Omega$, $\text{k}\Omega$, $\text{M}\Omega$) • Measuring small DC Current (mA) in series • Testing diodes and checking transistor gain ($h_{FE}$) |
| **04** | **Resistors & Ohm's Law** | Resistance function and types: carbon film and metal film • 4-band and 5-band color code calculation • Resistor wattage ratings ($1/4\text{W}$, $1/2\text{W}$, $1\text{W}$) and tolerance • Ohm's Law formula: $V = I \times R$, $I = V / R$, $R = V / I$ • Calculating current-limiting resistors for LEDs • Series resistor circuits ($R_{total} = R_1 + R_2$) • Parallel resistor circuits ($1/R_{total} = 1/R_1 + 1/R_2$) |
| **05** | **Switches & Variable Resistors** | Mechanical switch types: push button (momentary NO/NC), slide, toggle, and rocker switches • Magnetic reed switches • Potentiometers: construction, resistive track, and wiper pin • Rheostat configuration (2 pins) for current control • Voltage divider configuration (3 pins) for voltage control • Trimpots and circuit calibration |
| **06** | **Capacitors & Energy Storage** | What is a capacitor and electrostatic charge storage • Capacitance units: Farad, $\mu\text{F}$, $\text{nF}$, $\text{pF}$ • Electrolytic capacitors (polarised) and polarity safety • Ceramic capacitors (non-polarised) and 3-digit numeric codes • Capacitor voltage ratings • Charging and discharging curves • RC time constant ($\tau = R \times C$) • DC power supply filtering and ripple smoothing |
| **07** | **Diodes & Rectification** | Semiconductor P-N junction fundamentals • Forward bias ($0.7\text{V}$ drop) vs reverse bias (blocking state) • Anode and cathode identification • Light Emitting Diodes (LEDs): colors, forward voltage drops, and polarity • Zener diodes and voltage regulation • Half-wave rectification • Full-wave diode bridge rectifier (converting AC to DC) |
| **08** | **Bipolar Junction Transistors (BJT)** | What is a transistor and why it replaced vacuum tubes • BJT types: NPN (BC547, 2N3904) and PNP (BC557, 2N3906) • Pinout identification: Base (B), Collector (C), and Emitter (E) • Operation principle: base current controlling collector current • Operational regions: Cut-off (OFF switch), Saturation (ON switch), Active (Amplifier) • Transistor current gain ($\beta$ / $h_{FE}$) • Using a transistor as an electronic switch • Using a transistor as an audio/signal amplifier |
| **09** | **Relays & Electromechanical Control** | Relay working principle: coil, electromagnet, armature, and spring • Terminal identification: Common (COM), Normally Open (NO), Normally Closed (NC) • Electrical isolation between low-voltage control circuits and high-power loads • Inductive kickback (back-EMF) from de-energizing coils • Flyback (freewheeling) protection diodes • Driving relays with an NPN transistor |
| **10** | **Sensors & Input Transducers** | What is a sensor and converting physical phenomena to electrical signals • Light Dependent Resistors (LDR / photoresistor) • Thermistors (NTC / PTC) and temperature sensing (LM35) • Soil moisture sensor plates • Raindrop detection sensor • Electret microphone sound sensor • Passive Infrared (PIR) motion sensor • Ultrasonic distance sensor (HC-SR04) • Interfacing analog sensors using voltage divider circuits |
| **11** | **Analog Integrated Circuits: 555 Timer & Op-Amps** | What is an Integrated Circuit (IC), DIP packages, and pin numbering conventions • LM555 Timer IC internal structure: voltage divider, comparators, flip-flop, discharge transistor • 555 Astable mode (oscillator, square-wave clock, LED flasher) • 555 Monostable mode (one-shot timer, delay circuit) • Operational Amplifiers: LM358 dual op-amp pinout • Inverting (-), Non-inverting (+), and output pins • Open-loop voltage comparator mode: comparing sensor voltage to reference voltage • Setting adjustable sensitivity thresholds with potentiometers |
| **12** | **Voltage Regulators & Power Supplies** | Purpose of voltage regulation in electronics • Linear regulators: 7805 ($5\text{V}$), 7809 ($9\text{V}$), 7812 ($12\text{V}$) • Regulator pinout: Input, Ground, Output • Heat generation, power loss calculation, and heatsinks • Input filter capacitors and high-frequency output decoupling capacitors ($0.1\,\mu\text{F}$) • Building a stable regulated DC power supply |
| **13** | **Tools, Soldering & Circuit Assembly** | Hand tools: wire strippers, cutters, pliers, tweezers, and helping hands • Soldering iron components, wattage, and temperature selection • Rosin-core solder wire (60/40) and soldering flux • Soldering technique: cleaning tip, tinning, heating joint, feeding solder, and cooling • Inspecting solder joints: shiny concave fillets vs cold solder joints and solder bridges • Desoldering tools: desoldering pump (solder sucker) and desoldering copper braid wick • Transferring circuits from breadboard to General-Purpose Solderable Board (Zero-PCB / Perfboard) |
| **14** | **Microcontrollers & Programmable Systems** | What is a microcontroller: CPU, RAM, Flash memory, and GPIO on a single chip • Arduino Uno / Nano hardware map: power pins, digital I/O pins, PWM pins, and analog input pins • Writing and uploading code in Arduino IDE: `setup()` and `loop()` • Digital Output: `pinMode()` and `digitalWrite()` • Digital Input: push buttons and `digitalRead()` • Analog Input: 10-bit Analog-to-Digital Converter (ADC) and `analogRead()` • Pulse Width Modulation (PWM): duty cycle and simulated analog output via `analogWrite()` • Interfacing alphanumeric displays: 16×2 I2C LCD displays • Introduction to IoT: ESP8266 NodeMCU Wi-Fi connectivity |
| **15** | **Practical Electronics Projects** | Automatic dark-activated light using an LDR and BC547 transistor • Multi-level water level indicator using transistors and colored LEDs • Overheat / fire alarm using an NTC thermistor, LM358 comparator, and active buzzer • Alternating dual-LED flasher using a 555 Timer in astable mode • Touch-activated electronic switch using skin resistance and transistor base current • Regulated $5\text{V}$ bench power supply using a transformer, diode bridge rectifier, filter capacitor, and 7805 regulator • Smart contactless gate system using an Arduino, ultrasonic sensor (HC-SR04), and servo motor |
