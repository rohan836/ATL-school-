## Asset Classification Legend
- **Permanent Asset**: Durable, non-depleting capital equipment (e.g., Oscilloscope, Soldering Stations, Hand Tools, Power Tools, 3D Printer, UPS, Storage Racks, STEM kits) that remain in the lab permanently.
- **Consumable**: Material supplies, boards, and electronic components (e.g., Arduino Uno/Nano/Mega, Raspberry Pi, NodeMCU, Resistors, LEDs, Sensors, Displays, Motors, Jumper wires, Solder wire, Glue sticks) that get consumed, assembled, or built into student projects.
