# ATL Teacher Operational Guide & Weekly Teaching Plan

> **Scope**: Classes 5–9 (10 Batches, 400 Students)  
> **Timetable Reference**: [`SCHOOL-OPERATIONS/TIMETABLES/MAIN/ATL-LAB-TIMETABLE.md`](../../SCHOOL-OPERATIONS/TIMETABLES/MAIN/ATL-LAB-TIMETABLE.md)  
> **Core Formula**: 20 Minutes Concept Hook + 50 Minutes Hands-On Build  

---

## 1. Two-Teacher Co-Teaching Model (40 Students / 8 Teams)

* **Teacher 1 (Lead / Screen & Code)**:
  - Delivers the 20-minute concept introduction on the main projector.
  - Displays circuit schematics, pinout diagrams, and code snippets.
  - Controls lesson pacing and central classroom timer.
* **Teacher 2 (Floor / Hardware & Troubleshooting)**:
  - Moves between the 8 student tables continuously.
  - Fixes loose connections, wrong polarity, and breadboard bugs.
  - Distributes components and supervises tool/soldering bays.

---

## 2. The 70-Minute Classroom Structure

* **First 20–25 Minutes (Concept Hook)**:
  - Live component/circuit demonstration on the projector.
  - Schematic walk-through and clear 1-page build objective.
* **Next 45–50 Minutes (Hands-On Build & Wrap-Up)**:
  - 8 teams (5 students each) assemble the project immediately.
  - Floor teacher supports at table level; lead teacher keeps schematics/code on screen.
  - Final 5 minutes: check-in project boxes and clean tables.

---

## 3. Weekly Project Cycles by Grade

| Grade | Scheduled Days | Sessions / Week | Session Length | Weekly Project Focus |
|:---:|---|:---:|:---:|---|
| **Class 5** | Monday, Tuesday, Wednesday | 3 | 70–75 min | Craft circuits, basic switches, DC motors |
| **Class 6** | Thursday, Friday, Saturday | 3 | 70–75 min | Breadboard electronics, sensors, 555 timers |
| **Class 7** | Monday, Tuesday | 2 | 65–70 min | Arduino Uno, digital/analog I/O, automation |
| **Class 8** | Wednesday, Thursday | 2 | 65–70 min | Motor drivers, robotics, line followers |
| **Class 9** | Friday, Saturday | 2 | 60–70 min | ESP32/IoT, wireless telemetry, rovers |

### 3-Day Cycle (Classes 5 & 6)
* **Day 1**: Concept explanation + test individual sub-circuits.
* **Day 2**: Full project integration (chassis, motors, sensors).
* **Day 3**: Testing, demonstration, and student file documentation.

### 2-Day Cycle (Classes 7, 8 & 9)
* **Day 1**: Concept walk-through + complete hardware wiring.
* **Day 2**: Code upload, sensor calibration, arena testing, and file documentation.

---

## 4. Parallel Batch Rule: "Prepare 1, Teach 2"

* Batch C and Batch D attend on the same days in back-to-back slots.
* Teachers prepare **only 1 project per grade per week** (5 total project setups for the whole school).
* Setups remain on tables and projector between slots with a quick 10-minute turnaround.

---

## 5. Inventory Rule: "Showcase 1, Disassemble 7"

To prevent component shortages and build a permanent school display:
* **Preserve 1 Best Model**: The highest-quality build from each class is kept intact, labeled with student names, and placed on the ATL showcase shelf.
* **Disassemble 7 Models**: The remaining 7 builds are taken apart and sorted back into component bins for next week's classes.

---

## 6. Student File Documentation (1 Page per Project)

At the end of each project, every student writes a 1-page entry in their practical file:
1. **Title & Team Info**: Project name, date, class, team member names.
2. **Bill of Materials (BOM)**: Components, ratings, and quantities used.
3. **Hand-Drawn Schematic**: Standard circuit symbols drawn clearly.
4. **Working Principle**: 3–4 sentences explaining how the circuit functions.
5. **Troubleshooting Log**: 1 error encountered (e.g. reversed polarity) and how it was resolved.

---

## 7. Operational Needs Checklist

* **8 Table Tool Caddies**: Plier, wire stripper, multimeter, and screwdrivers at each table.
* **80 Labeled Storage Boxes**: Clear boxes (`Class 5C — Grp 1` to `Class 9D — Grp 8`) for multi-day in-progress work.
* **Projector / Display**: Kept ready for schematics and live code.
* **Printed Assignment Log Sheets**: Ready for student documentation at each session end.
