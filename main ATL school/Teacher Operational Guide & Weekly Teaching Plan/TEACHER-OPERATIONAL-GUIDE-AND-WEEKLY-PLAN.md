# ATL Teacher Operational Guide & Weekly Teaching Blueprint

> **Target Audience**: ATL Teaching Staff (Lead Instructor & Floor Instructor)  
> **Academic Scope**: Classes 5 to 9 (10 Batches, 400 Total Students)  
> **Source Timetable**: Integrated with Official Bell Schedule (`SCHOOL-OPERATIONS/TIMETABLES/MAIN/ATL-LAB-TIMETABLE.md`)  
> **Core Teaching Philosophy**: **20 Minutes Concept Hook + 50 Minutes Hands-On Project Build**  

---

## 1. The Two-Teacher Co-Teaching Model

Our lab sessions run with **two coordinated instructors** to manage 40 students (8 working groups) smoothly and safely:

```
┌────────────────────────────────────────────────────────────────────────┐
│             TEACHER 1 (Lead Anchor / Screen & Code Lead)               │
│  - Stands at Main Projector / Smart Display                            │
│  - Delivers the 20-minute concept introduction                         │
│  - Displays reference schematics, circuit pinouts & live code blocks   │
│  - Keeps the central classroom timer and guides lesson pacing          │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ Works in sync with
┌───────────────────────────────────┴────────────────────────────────────┐
│           TEACHER 2 (Floor Facilitator / Hands-On Troubleshooter)      │
│  - Moves continuously across the 8 student tables                      │
│  - Troubleshoots loose jumper wires, wrong polarity & breadboard bugs  │
│  - Distributes components and supervises the soldering/cutting bay     │
│  - Keeps all 8 groups moving at the same pace without stopping lecture │
└────────────────────────────────────────────────────────────────────────┘
```

## 2. The 70-Minute Classroom Formula: "Concept to Creation"

Students get bored quickly if taught pure theory on a blackboard. To maximize excitement and retention, every single 65–75 minute session follows this exact split:

```
┌───────────────────────────┬────────────────────────────────────────────┐
│   FIRST 20–25 MINUTES     │            NEXT 45–50 MINUTES              │
│    "The Concept Hook"     │        "Hands-On Project Build"            │
├───────────────────────────┼────────────────────────────────────────────┤
│ • Real-world demonstration│ • 8 Teams (5 kids each) build immediately  │
│ • Component deep-dive     │ • Floor Teacher debugs at table level      │
│ • Schematic on projector  │ • Lead Teacher holds live code on screen   │
│ • Clear 1-page objective  │ • 5-min clean-up & project box check-in    │
└───────────────────────────┴────────────────────────────────────────────┘
```

## 3. Weekly Timetable Integration & Project Cycles

Based on our school's official bell schedule, each batch attends on **consecutive days**. This allows a complete 1-week project cycle from introduction to showcase:

| Grade | Scheduled Days | Weekly Sessions per Batch | Session Length | Weekly Project Format |
|:---:|---|:---:|:---:|---|
| **Class 5** | Monday, Tuesday, Wednesday | **3 Sessions** | 70–75 min | **3-Day Project Cycle** (Craft Circuits & Motors) |
| **Class 6** | Thursday, Friday, Saturday | **3 Sessions** | 70–75 min | **3-Day Project Cycle** (Breadboards & 555 Timers) |
| **Class 7** | Monday, Tuesday | **2 Sessions** | 65–70 min | **2-Day Project Cycle** (Arduino Uno Automation) |
| **Class 8** | Wednesday, Thursday | **2 Sessions** | 65–70 min | **2-Day Project Cycle** (Robotics / Line Follower) |
| **Class 9** | Friday, Saturday | **2 Sessions** | 60–70 min | **2-Day Project Cycle** (IoT, Wi-Fi & Drones) |

---

### A. The 3-Day Project Blueprint (Classes 5 & 6)

* **Day 1 (Concept Hook & Sub-Circuit Testing)**:
  - *Min 00–25*: Teacher 1 explains the component (e.g., LDR sensor or Resistor color codes) using live meter tests on the projector.
  - *Min 25–65*: Students build small test circuits on their breadboards to observe the behavior (e.g., LED lights up when room gets dark).
  - *Min 65–70*: Store parts in the team project box.
* **Day 2 (Full Project Integration & Build)**:
  - *Min 00–15*: Quick recap of yesterday's findings; Teacher 1 displays the full project diagram.
  - *Min 15–65*: Teams mount motors, assemble chassis/craft boxes, and complete the full system. Teacher 2 guides fine wiring at the tables.
  - *Min 65–70*: Progress check-in and box storage.
* **Day 3 (Testing, Exhibition & Assignment Documentation)**:
  - *Min 00–35*: Teams test their finished project, tune sensitivity, and demonstrate working output to teachers.
  - *Min 35–65*: **Student Assignment File Work**: Students draw their circuit schematic by hand, write down the component list, and write 3 key learnings in their lab record file.
  - *Min 65–70*: One model preserved for showcase; remaining models safely dismantled.

---

### B. The 2-Day Project Blueprint (Classes 7, 8 & 9)

* **Day 1 (Concept, Schematic & Hardware Wiring)**:
  - *Min 00–25*: Teacher 1 explains the theory and algorithm (e.g., H-Bridge motor logic, IR line reflection) and projects the pinout map.
  - *Min 25–65*: Teams assemble the physical hardware (chassis, motors, sensors) and complete all wiring connections to the Arduino/ESP board.
  - *Min 65–70*: Store assembled hardware in labeled project boxes.
* **Day 2 (Coding, Calibration, Arena Testing & Documentation)**:
  - *Min 00–20*: Teacher 1 walks through the code logic block-by-block on the projector.
  - *Min 20–50*: Students upload code, calibrate sensor trimmers, and test their robots on the floor arena track. Teacher 2 troubleshoots code errors and pin misalignments.
  - *Min 50–65*: **Student Assignment Documentation**: Students draw the schematic and write down code logic and troubleshooting notes.
  - *Min 65–70*: Best robot kept for ATL Showcase; remaining 7 robots disassembled.

## 4. The "Parallel Batch" Teacher Workload Trick

A huge advantage of our school's timetable is that **Batch C and Batch D attend on the exact same days in back-to-back slots**:
- *Monday Slot 1 (7:20 AM)*: Class 5C
- *Monday Slot 2 (8:45 AM)*: Class 5D

### Why This Makes Teaching Simple:
1. **Prepare Once, Teach Twice**: The two teachers only need to prepare **one project per grade per week**.
2. Everything set up for Batch C remains ready on the projector and tables for Batch D immediately after the 10-minute break.
3. Across the entire school week, teachers only manage **5 unique projects** across all 10 batches.

## 6. Student Project Assignment & File Work

Every student maintains an **ATL Practical Project File**. At the end of every weekly project, each student completes a clean 1-page report:
1. **Project Title & Team Details**: Project name, date, class, and 5 team member names.
2. **Bill of Materials (BOM) Table**: Name of each part, specification, and quantity used.
3. **Hand-Drawn Circuit Diagram**: Hand-drawn schematic using proper electrical symbols (resistor, LED, battery, switch, ground).
4. **How It Works (In Simple Words)**: 3–4 sentences describing the operational logic.
5. **Troubleshooting Note**: One problem the team faced (e.g. *"Motor was spinning backwards"*) and how they fixed it (*"Swapped positive and negative motor wires"*).

## 7. Operational Needs Checklist

### What the Teachers Need (To Run Classes Smoothly):
- **8 Table Caddies**: Each student table has 1 bin with basic tools (pliers, screwdriver, multimeter, wire stripper).
- **Project Box Shelf**: 80 labeled clear plastic boxes (`Class 5C — Grp 1` to `Class 9D — Grp 8`) so in-progress projects never mix up.
- **Projector / Large Display**: In working condition so Teacher 1 can keep schematics and code visible to all 40 students.
- **Printed Student Assignment Sheets**: Ready for students to sketch and write their weekly log.

### What the School Achieves:
- **Zero Component Waste**: Reusable kits circulate year-round; no expensive components are left forgotten in drawers.
- **Measurable Academic Output**: Every student leaves with a complete portfolio of 15–20 hand-drawn circuit schematics and engineering logs per year.
- **Permanent School Trophy Shelf**: 1 showcase model preserved from every project cycle, creating an impressive lab display for visitors, parents, and inspectors.
