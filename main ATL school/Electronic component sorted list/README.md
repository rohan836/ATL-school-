2. **Category Cleansing**: Split mixed packages (Packages 1–4) into clean, logical physical categories so teachers and students can locate items immediately.
3. **Specification Enrichment**: Preserved all official voltage, current, pinout, and dimensional data from the original ATL specification guidelines.
