# ATL Lab Teaching Timetable

## Purpose

This timetable is for electronics, robotics, and project-based practical lessons in the Atal Tinkering Lab (ATL). It covers Classes 5–9. Each class has two batches: C and D.

The teaching plan keeps each class's C and D batches in consecutive periods. This lets the teacher prepare one practical, teach it to C, then repeat it for D. It also places sessions for each class on consecutive days so students can continue a project from one session to the next.

## Fixed constraints

- Classes: 5, 6, 7, 8, and 9.
- Batches: C and D for each class (10 batches).
- Working days: Monday to Saturday (6 days).
- Periods per day: 4.
- Length of each period: 70 minutes.
- Weekly capacity: 24 periods = 1,680 minutes = 28 teaching hours.
- C and D for the same class are taught in consecutive periods.
- Classes 5, 6, and 7 have 2 sessions per batch each week.
- Classes 8 and 9 have 3 sessions per batch each week.

## Project continuity across sessions

Use each class's sessions as a sequence. Continue the same project instead of starting a new practical at every lesson.

- **Class 5 — Monday and Tuesday:** introduce the concept and start the build on Monday; continue, test, and record the result on Tuesday.
- **Class 6 — Wednesday and Thursday:** introduce the concept and start the build on Wednesday; continue, test, and record the result on Thursday.
- **Class 7 — Friday and Saturday:** introduce the concept and start the build on Friday; continue, test, and record the result on Saturday.
- **Class 8 — Monday, Tuesday, and Wednesday:** learn the concept and plan the build on Monday; build and test on Tuesday; improve and demonstrate on Wednesday.
- **Class 9 — Thursday, Friday, and Saturday:** learn the concept and plan the build on Thursday; build and test on Friday; improve and demonstrate on Saturday.

These are suggested project stages. Adjust them to suit the practical, student progress, and component availability.

## Repeatable lesson workflow

For each scheduled batch:

1. Start with a short challenge or question.
2. Explain the electronics concept and demonstrate safe component use.
3. Let students build or continue the practical.
4. Test the circuit or project and ask students to explain the result.
5. Record progress and the next step.
6. Reset or replenish components before the next batch.

Teach C first and D immediately after it using the same lesson plan and practical. Keep both batches at a similar stage.

## Capacity check

- 6 days × 4 periods per day = 24 periods per week.
- 24 periods × 70 minutes = 1,680 minutes = 28 teaching hours per week.
- Classes 5, 6, and 7: 2 sessions per batch × 2 batches = 4 periods per class per week.
- Classes 8 and 9: 3 sessions per batch × 2 batches = 6 periods per class per week.
- Total: 3 classes × 4 periods + 2 classes × 6 periods = 24 periods per week.

## Important checks

- Confirm that the school allows these batches to attend the ATL lab on the listed days.
- Confirm the school's bell times and break schedule. The table lists periods, not exact clock times.
- This plan assumes the same practical can be repeated for C and D and that components are available for both batches.
- If a session is cancelled, record the missed batch and schedule a make-up session so that C and D keep the same progress.
