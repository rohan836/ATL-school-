# ATL Lab Teaching Timetable

## Purpose

This timetable helps the ATL teacher deliver electronics, robotics, and project-based practical lessons to Classes 5–9. Each class has two batches: C and D.

The main rule is to teach the same class level's C and D batches one after the other. This lets the teacher prepare one practical, teach it to C, and repeat it for D with the same components and lesson plan.

## Fixed constraints

- Class levels: 5, 6, 7, 8, and 9.
- Batches: C and D for each class level (10 batches total).
- Working days: Monday to Saturday (6 days).
- Teaching periods: 4 periods per day.
- Period length: 70 minutes.
- Weekly capacity: 24 periods, or 1,680 minutes (28 hours) of teaching.
- Each period is one batch lesson.
- C and D lessons for the same class level should be consecutive whenever possible.

## Scheduling logic

There are 10 batches and 24 periods per week. Equal whole-period allocation is not possible in a single week because 24 does not divide evenly by 10.

Use a five-week rotation:
- Every class-level pair (for example, 5C and 5D) is taught together in consecutive periods.
- Each class level receives 12 paired sessions across five weeks.
- Each paired session gives one period to C and one period to D.
- Therefore, each batch receives 12 periods in five weeks, or 840 minutes (14 hours).
- In a typical week, some class levels receive three sessions and others receive two. The rotation moves the extra sessions between class levels.
- Total capacity over five weeks is 120 periods. Each of the 10 batches receives 12 periods, so all batches receive equal teaching time over the full rotation.

## How to read the timetable

Each day has two consecutive C/D pairs:
- Periods 1–2: one class level; teach C first, then repeat the same practical for D.
- Periods 3–4: another class level; teach C first, then repeat the same practical for D.

The exact clock times depend on the school's bell schedule. Each period is 70 minutes, so confirm break times and start times with the school.

## Practical teaching workflow

1. Prepare one lesson plan and component set for each class level.
2. Teach the practical to the C batch.
3. Reset or replenish the components, then teach the same practical to the D batch.
4. Record the topic, components used, student progress, and any follow-up work.
5. Use the next session for the next step of the project. Keep C and D at the same stage where possible.

## Important checks

- Confirm that the school timetable allows the same class level's C and D batches in consecutive periods.
- Confirm that all four periods are available each day and that breaks do not reduce the teaching time.
- If a school event cancels a period, record the missed batch and use a make-up period. Do not silently change the five-week balance.
- This is a planning timetable. Confirm class availability and school rules before treating it as final.

## Rotation verification

Each class level appears 12 times in the five-week schedule. Each appearance uses two periods: one for C and one for D. Thus each batch receives 12 periods over five weeks.

- Total periods: 5 weeks × 6 days × 4 periods = 120.
- Total batch periods: 10 batches × 12 periods = 120.
- Teaching time per batch: 12 × 70 minutes = 840 minutes = 14 hours.
