Separate AI literacy pathway without electronics, robotics, hardware, or coding prerequisites.

**Progression:** Class 5 builds concrete AI literacy; Class 6 applies and tests simple paper models; Class 7 compares learning approaches and evaluates small examples; Class 8 analyses more advanced AI system concepts with teacher scaffolding; Class 9 designs and defends evidence-aware evaluations and responsible system proposals.

The progression is designed for typical learners at these grade levels. Teachers should use diagnostic checks and adapt scaffolding to actual student readiness. Advanced concepts in Classes 8–9 are conceptual unless an optional extension is explicitly stated.

This is a proposed AI literacy pathway, not an official CBSE syllabus. See the alignment guide for the review rubric and the limits of the audit.
