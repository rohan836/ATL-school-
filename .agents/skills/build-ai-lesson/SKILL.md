# ATL AI & Python Lesson Skill

Use this skill when planning, updating, or facilitating any AI & Python session or project under `CURRICULUM/CLASSES/AI/`.

## 1. Required Reading First
1. Read `CURRICULUM/CLASSES/AI/AGENTS.md` and `CURRICULUM/CLASSES/AI/AI-CURRICULUM-CLASSES-5-TO-9.md`.
2. Read the target grade's `CLASS-<N>-CURRICULUM.md` and `SKILL.md` inside `CURRICULUM/CLASSES/AI/Class-<N>/`.

## 2. Curriculum File Rules
- **Master File (`AI-CURRICULUM-CLASSES-5-TO-9.md`):** Holds **Term 1: The Connected Foundations (Contents 1–6)** and **Term 2: Building Real AI Systems (Contents 7–12)** across `Class 5` through `Class 9` word-for-word.
- **Per-Class Files (`CLASS-<N>-CURRICULUM.md`):** Mirror the exact `Term 1` (Contents 1–6) and `Term 2` (Contents 7–12) rows (`| # | Content & Core Concept *(Taught in ALL Grades 5–9)* | Class <N> |`) word-for-word for that grade.
- **Strict Separation & Zero Clutter:** Never add extra words to the curriculum files, never create `PROJECTS.md` files, and never reference external Electronics classes.
- **Regenerate HTML:** Run `python3 CURRICULUM/build_html.py` after Markdown edits.
