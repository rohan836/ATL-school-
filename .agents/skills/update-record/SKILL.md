# Update Record

Use this workflow when the owner asks to correct, refresh, extend, or change an existing record.

## Procedure
1. Read `AGENTS.md`, `PROJECT.md`, and the relevant `INDEX.md` entry.
2. Locate and read the current authoritative record. Search for related copies or linked records that may be affected.
3. Determine the exact requested change. If the target, meaning, or authority is unclear, ask before editing.
4. Follow the permission rules in `AGENTS.md`. A request to update one record does not authorize unrelated changes, moves, deletions, or broad restructuring.
5. Preserve information that remains valid. Distinguish new values from old values or historical context when that distinction matters.
6. Update related records only when the request and evidence support it. Keep representations consistent where they are intended to match.
7. Verify the result, relevant dates, calculations, links, and source-of-truth relationship.
8. Report what changed and any unresolved conflict or uncertainty.

## Important
Never infer that a proposal has been approved, work has been completed, or a record is current solely because it was edited.
